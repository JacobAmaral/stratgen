## Platform

## Users

Independent quantitative traders, systematic retail and prop traders, and algorithmic strategy developers running on Windows 10/11 who want to research, validate, and deploy rule-based strategies across futures, equities, crypto, and forex without hand-writing platform code.

## Product Purpose

StratGen is a Windows desktop application by WeTradeLabs Inc. (founded by Jacob Amaral) for designing, backtesting, robustness-testing, and exporting algorithmic trading strategies. Success for a visitor on stratgensoft.com is understanding how StratGen's workflow prevents curve-fitting and ships live-ready code, inspecting real application screens and documentation, and subscribing ($99/month) or purchasing lifetime access ($1,000 one-time).

## Positioning

Combines a high-speed v2 Tensor backtest and multi-window walk-forward engine, an AI Copilot Conversational Studio with autonomous Roslyn C# verification, 600+ technical and fundamental signals, portfolio correlation and Monte Carlo robustness testing, direct code generation for NinjaTrader, TradeStation, and Python, and live training on best practices included with every plan.

## Operating Context

Traders evaluate StratGen alongside execution platforms (NinjaTrader, TradeStation, Python environments) and custom OHLCV datasets. The website serves both as the primary commercial surface (`/` and `/what-is-stratgen`) and the technical reference (`/user-manual`, `/changelog`, `/terms-and-conditions`, `/privacy-policy`).
